## First passage

This document checks how the reader follows a spoken sentence. The second sentence must become highlighted while the first paragraph stays in view. The third sentence is here to verify that the position advances within a paragraph.

This is a separate paragraph with **bold text** and *italic words*. Reading should keep the original formatting and make each new passage visible.

## A longer passage

Reading should feel comfortable on a small screen as well as a large one. When a listener scrolls away to check an earlier sentence, the page should respect that choice. The listener can then press Resume following to return to the current passage. Opening a note should not cause the document to jump while the note is being written. Changing the voice or speed should keep the current location available. Search should continue to find words even when a sentence has been highlighted. Existing notes and saved highlights should remain attached to their original passages.
